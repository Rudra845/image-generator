# 🎨 DreamCanvas AI - Free Text to Image Generator

A web application built with **HTML5, CSS3, and JavaScript** that creates AI-generated images from text prompts with customizable picture styles, aspect ratios/sizes, and batch quantities — **100% Free with No Token, API Key, or Login Required!**

---

## ✨ Features Included

### 1. 📝 Prompt Input & Creative Tools
- **Description Input**: Write any creative prompt with character counter.
- **🎲 Surprise Me**: 1-click button to load rich creative prompts across fantasy, sci-fi, cyberpunk, architecture, and 3D scenes.
- **Negative Prompt Support**: Specify unwanted artifacts (e.g. blurry, distorted, watermark).
- **Lighting & Enhancer Tags**: Quick toggle tags (*Dramatic Lighting, Golden Hour, Volumetric Fog, 8K Octane Render, Studio Lighting, Neon Glow*).

### 2. 🤖 AI Diffusion Models (Free)
- **FLUX.1** (High Detail & Flagship Quality)
- **SDXL Turbo** (Ultra Fast Realtime Generation)
- **Anime & Manga** (Specialized Anime Diffusion)

### 3. 🎨 12 Picture Styles / Types
- **Default / Raw**
- **Photorealistic** (8K DSLR Photography)
- **Anime & Manga** (Studio Ghibli / Makoto Shinkai style)
- **Cyberpunk** (Neon, sci-fi cityscapes)
- **3D Render** (Pixar / Disney character style)
- **Oil Painting** (Masterpiece canvas)
- **Concept Art** (Digital matte painting)
- **Watercolor** (Fluid artistic ink bleeding)
- **Fantasy Epic** (Glowing runes & magic)
- **Pixel Art** (16-bit retro arcade)
- **Cinematic** (35mm movie stills)
- **Vintage Retro** (1970s polaroid film)

### 4. 📐 Picture Size & Aspect Ratio
- **1:1 Square** (1024 × 1024)
- **16:9 Landscape** (1280 × 720)
- **9:16 Story / Reel** (720 × 1280)
- **4:3 Standard** (1024 × 768)
- **3:4 Portrait** (768 × 1024)
- **21:9 Ultra-Wide** (1280 × 548)

### 5. 🔢 Number of Pictures (1 to 4 Batch Generation)
- Generate **1, 2, 3, or 4 pictures** at the same time with distinct seeds and variations.

### 6. 🖼️ Output Features
- 🔍 **Fullscreen Lightbox** zoom modal.
- 💾 **Instant Download** (`.jpg`) with customized file slug.
- 📥 **Batch Download All** button.
- 📋 **Copy Prompt** button.
- ❤️ **Favorites** system.
- 📜 **Generation History Drawer** stored in browser `localStorage`.
